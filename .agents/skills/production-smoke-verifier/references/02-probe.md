# Step 2: Probe

Run configured:

1. health and static asset requests;
2. public configuration/version requests;
3. deployment and version listings;
4. secret-name listings;
5. read-only data queries;
6. negative unauthenticated requests that cannot create state.

Capture status, content type, deployment identity, and whether any write counter changed.

Proceed to [Step 3: Confirm](03-confirm.md).
