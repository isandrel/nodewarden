# Step 2: Isolate

Compare:

- first load versus reload;
- controlled versus uncontrolled browser context;
- public CDN domain versus direct origin;
- online versus offline;
- navigation request versus prefetch;
- exact protocol page versus SPA fallback;
- current HTML asset hashes versus cached hashes.

Change one layer at a time and retain evidence.

Proceed to [Step 3: Remediate](03-remediate.md).
