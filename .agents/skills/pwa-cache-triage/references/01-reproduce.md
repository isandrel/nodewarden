# Step 1: Reproduce

Capture:

1. exact URL, action, and visible symptom;
2. navigation entries and initiators;
3. console errors;
4. active service-worker script, scope, and controller;
5. response status, content type, cache headers, and deployment marker;
6. cached entry names relevant to the failing route.

Proceed to [Step 2: Isolate](02-isolate.md).
