# Step 3: Report

Report:

1. Exact ref/SHA table and divergence.
2. Release and CI status.
3. Commit-by-commit behavior changes.
4. Data, schema, deployment, and security impact.
5. Predicted conflicts and required resolutions.
6. Recommendation: wait, sync exact SHA, or sync tagged release.
7. Gated next steps and actions explicitly not performed.

Never imply that a review pushed, deployed, backed up, or tested production unless direct evidence proves it.
