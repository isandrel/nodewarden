# Step 2: Compare Behavior

Compare:

- request and response fields, casing, optionality, and encoding;
- error status and message contracts;
- unknown-field preservation;
- origin, CORS, frame, callback, and post-message validation;
- mobile deep links, desktop custom origins, and browser-extension origins;
- offline, fallback, and unsupported-client behavior.

Treat a copied implementation as evidence only after checking its surrounding security assumptions.

Proceed to [Step 3: Verify](03-verify.md).
