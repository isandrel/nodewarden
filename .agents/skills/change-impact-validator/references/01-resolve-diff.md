# Step 1: Resolve the Diff

1. Read repository instructions and determine whether the target is a working tree, commit, branch, or pull request.
2. Resolve exact base and head revisions.
3. Include untracked files for working-tree reviews.
4. Record whether generated files and dependency locks are authoritative or derived.

Do not mix unrelated pre-existing changes into the validation target.

Proceed to [Step 2: Select Checks](02-select-checks.md).
